# Simulate Security Log Monitoring

This example simulates a basic Security Operations Center (SOC) monitoring process. It reads a log file, identifies predefined suspicious patterns like failed logins or malware alerts, and generates incident alerts. This demonstrates the core SOC function of detecting and responding to potential cyber threats by continuously analyzing security logs.

## Language

`python`

## How to Run

1. Ensure Python is installed (version 3.6+).
2. Save the code as `soc_monitor.py`.
3. Run `python soc_monitor.py` in your terminal. The script will automatically create a dummy `security_logs.log` file if it doesn't exist.
